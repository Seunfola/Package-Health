Quick Start

Submit a GitHub repository URL, paste a package.json, or upload a manifest file directly from the homepage — no login required for public repositories. DepVault reads only the dependency manifest; your source code is never uploaded or stored.

Every scan produces a single Trust Score (0–100), weighted across four dimensions:

  • Security — 45%: known vulnerabilities, weighted by a Poisson CDF and the package's structural criticality.
  • License — 20%: penalizes non-permissive or toxic copyleft licenses (GPL, AGPL).
  • Maintenance — 20%: commit frequency, release cadence, and general repository health.
  • Popularity — 15%: weekly downloads and dependent count.
