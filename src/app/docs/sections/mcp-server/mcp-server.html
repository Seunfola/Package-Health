MCP Server — For AI Coding Agents

@deepvaultscan/mcp-server is published to the public npm registry and lets any Model Context Protocol-compatible agent (Claude Code, Cursor, Windsurf) check a package's Trust Score on demand. 

{
  "mcpServers": {
    "depvault": {
      "command": "npx",
      "args": ["-y", "@deepvaultscan/mcp-server"]
    }
  }
}
ToolUse it to
scan_package_healthScore a single package before adding it as a dependency.
scan_repositoryScore every dependency in a project's manifest at once.

Optional auto-scan on install: npx @deepvaultscan/mcp-server --enable-auto-scan persists an opt-in flag so future npm installs scan automatically; add --block-on-critical to fail an install that pulls in a known CRITICAL-severity vulnerability. Both are off by default and report-only unless explicitly enabled — every tool call requires live internet access, there is no offline mode for the MCP server.

Important: MCP auto-scan is a convenience feature, not an all-install interceptor. It runs when this package's own install lifecycle runs and cannot protect unrelated future npm install commands. Use CLI Shield hooks or GitHub Actions for an actual install or merge gate.
