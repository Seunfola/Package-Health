Organizations & custom settings

Dashboard Settings centralizes members, notifications, webhooks, personal upload tokens, and Gatekeeper policies. FREE uses the safe default policy; PAID unlocks organization-wide customization. See Pricing for limits.

Use a personal API token only for depvault login and local depvault upload; do not add it to a repository or client-side source code.

Notifications Center

Every health-score change, new vulnerability, and LeakGuard finding above a threshold can raise a notification. The Notifications Center supports searching, filtering by repository, marking one or many as read, and deleting individually, in bulk, or all at once. Clean up old (30d+) removes your own read notifications past that age in one action — it never touches anyone else's.
