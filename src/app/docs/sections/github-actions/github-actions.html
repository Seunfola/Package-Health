GitHub Actions

The composite action scores the checked-out manifest, writes a job summary, can update one pull-request comment, and fails the job when the average Trust Score is below your threshold. It runs on your GitHub runner and needs no account, backend, or API key.

# .github/workflows/depvault.yml
name: DepVault Scan
on: [pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write # required only for PR comments
    steps:
      - uses: actions/checkout@v4
      - uses: Seunfola/package-health-backup/apps/github-action@v1
        id: depvault
        with:
          fail-below: '80'
          ignore-dev: 'false'
InputDefaultDescription
path.Directory relative to repository root.
fail-belowconfig valueMinimum average score; falls back to depvault.json.
risk-levelconfig / mediumlow, medium, or high.
comment-prtruePost or update one PR comment.
job-summarytrueWrite the Actions job summary.

The action exposes score, passed, and critical-count outputs. Pin to a release tag or commit SHA rather than a moving branch. Reporting runs before the final failure, so reviewers see package-level results even on a blocked pull request.
