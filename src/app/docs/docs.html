How DepVault Works

Quick Start

Submit a GitHub repository URL, paste a package.json, or upload a manifest file directly from the homepage — no login required for public repositories. DepVault reads only the dependency manifest; your source code is never uploaded or stored.

Every scan produces a single Trust Score (0–100), weighted across four dimensions:

  • Security — 45%: known vulnerabilities, weighted by a Poisson CDF and the package's structural criticality.
  • License — 20%: penalizes non-permissive or toxic copyleft licenses (GPL, AGPL).
  • Maintenance — 20%: commit frequency, release cadence, and general repository health.
  • Popularity — 15%: weekly downloads and dependent count.

MCP Server — For AI Coding Agents

@deepvaultscan/mcp-server is published to the public npm registry and lets any Model Context Protocol-compatible agent (Claude Code, Cursor, Windsurf) check a package's Trust Score on demand. 

{
  "mcpServers": {
    "depvault": {
      "command": "npx",
      "args": ["-y", "@deepvaultscan/mcp-server"]
    }
  }
}
ToolUse it to
scan_package_healthScore a single package before adding it as a dependency.
scan_repositoryScore every dependency in a project's manifest at once.

Optional auto-scan on install: npx @deepvaultscan/mcp-server --enable-auto-scan persists an opt-in flag so future npm installs scan automatically; add --block-on-critical to fail an install that pulls in a known CRITICAL-severity vulnerability. Both are off by default and report-only unless explicitly enabled — every tool call requires live internet access, there is no offline mode for the MCP server.

CLI — Shield & Install Hooks

The CLI is not yet published to the public npm registry — it's built from this project's source today. 

depvault shield express@4.18.2   # pre-scan one package, then install if it passes
depvault shield audit            # audit all currently installed packages
depvault hooks install           # print shell wrappers that gate npm/pnpm/yarn/pip/cargo/go installs

depvault shield <pkg> only gates the exact command you run. depvault hooks install is the real always-on gate — it prints shell functions that route every install through Shield first, blocking on a BLOCK verdict unless overridden with --force (audited, not silent).

Offline use: depvault shield sync downloads a signed verdict cache while online; if the backend later becomes unreachable, cached packages still get a real verdict — anything not already cached fails closed.
