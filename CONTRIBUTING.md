# Contributing

## Setup

```bash
pnpm install
pnpm run test
```

## Pull Request Style

- Keep PRs small and focused.
- Include a clear title and summary.
- Add tests for behavior changes.

## Co-Authored Commits (Pair Extraordinaire)

Use this trailer in the commit message:

```text
Co-authored-by: Name <email@example.com>
```

Example:

```text
feat: improve private repo analysis UX

Co-authored-by: Teammate Name <teammate@example.com>
```

## Quickdraw-Friendly Practice

- Watch active repos and pick newly opened issues.
- Open a targeted fix PR quickly with tests.
- Avoid broad refactors in first contribution PRs.

## Discussion Contributions (Galaxy Brain)

- Provide practical, tested answers.
- Include steps, command output, and links when possible.
- Follow up until the thread is resolved.
